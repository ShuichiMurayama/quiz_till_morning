# クイズ！朝までそれ正解 — セットアップ手順

## 中身

| ファイル | 役割 |
|---|---|
| `index.html` | ゲーム本体（これ1枚で動きます。お題も内蔵） |
| `questions.json` | お題データ。`index.html` と同じ場所に置くと、こちらが優先されます |
| `sw.js` | 一度開いたページを端末に保存し、電波が弱くても起動できるようにする仕組み |
| `database.rules.json` | Firebase のセキュリティルール（コピペ用） |

## まず試す（設定なし・5秒）

`index.html` をブラウザで開くだけで **デモモード** で動きます。
同じブラウザのタブ同士でのみ同期するので、招待画面の「＋ 新しいタブで参加」で参加者を増やして一通り遊べます。

## 本番用：Firebase を設定する（約10分・無料）

### 1. プロジェクトを作る
1. https://console.firebase.google.com/ を開き「プロジェクトを作成」
2. 名前は何でもOK（例：`asamade-quiz`）。Google アナリティクスはオフで構いません

### 2. 匿名ログインを有効にする
1. 左メニュー「構築 → Authentication」→「始める」
2. 「Sign-in method」タブ →「匿名」→ 有効にして保存

参加者はアカウント登録なしで、スマホごとに自動で識別されます。

### 3. Realtime Database を作る
1. 左メニュー「構築 → Realtime Database」→「データベースを作成」
2. ロケーションは **シンガポール（asia-southeast1）** がおすすめ（日本から最も近い）
3. 「ロックモードで開始」を選んで作成
4. 「ルール」タブを開き、中身を全部消して `database.rules.json` の内容を貼り付け →「公開」
5. **主催者の合言葉を決める**：「データ」タブで、一番上の項目の「＋」から次のように追加
   - キー `config` → その中に キー `hostKey`、値に好きな合言葉（例：`bonenkai2026`）
   - 部屋を作れるのは、この合言葉を知っている人だけになります（参加はQR/URLだけでOK）

### 4. 設定値を index.html に貼る
1. 歯車アイコン「プロジェクトの設定」→「マイアプリ」→ ウェブ（`</>`）アイコンでアプリを登録（Hosting のチェックは不要）
2. 表示される `firebaseConfig` の値を、`index.html` 冒頭の `FIREBASE_CONFIG` にコピー

```js
const FIREBASE_CONFIG = {
  apiKey: "AIza....",
  authDomain: "asamade-quiz.firebaseapp.com",
  databaseURL: "https://asamade-quiz-default-rtdb.asia-southeast1.firebasedatabase.app",
  projectId: "asamade-quiz",
  appId: "1:...:web:..."
};
```

> `databaseURL` が表示されない場合は、Realtime Database の画面上部にある URL（`https://〜.firebasedatabase.app`）を貼ってください。
> apiKey はページに書いても問題ない値です（守っているのはステップ3のルール）。

### 5. ネットに置く（どれか1つ）
- **Netlify Drop（いちばん簡単）**：https://app.netlify.com/drop に `index.html`・`questions.json`・`sw.js` を入れたフォルダをドラッグ → URL が発行されます
- **GitHub Pages**：リポジトリに3ファイルを置き、Settings → Pages で公開

発行された URL をスマホで開いて「部屋をつくる」→ 招待QRを見せれば参加できます。

## 当日の流れ

1. 主催者が「部屋をつくる」→ 👥 ボタンで招待QRを表示し、みんなに読み取ってもらう
2. お題を決める：赤い丸の **頭文字**（タップで50音から指定／🔀でランダム）と **テーマ**（🔀でランダム／✍️自分で書く）を選び、制限時間（秒数）を入力して「出題する！」
3. 全員が回答すると（または時間切れで）自動で公開フェーズへ
4. 回答の公開
   - 主催者：名前をタップして指名、または「🎲 ランダム指名」
   - 参加者：「公開する」で自分から公開（ロビーの設定でオフにもできます）
   - 自分と同じ答えのカードをタップ →「同じ！」で合流（カードの人数が増えます）
5. 全員出揃ったら、みんなで議論！ 納得の答えが決まったら主催者が「正解を決める」→ カードを選んで「これが正解！」
6. 正解発表（ハンコと紙吹雪）。正解グループ全員に +1
7. 締めは「🏆 最終結果」で表彰台を発表

## 電波が悪いお店での運用（おすすめ）

このゲームは「最初にページを開くとき」が一番重く、遊んでいる最中の通信は1操作あたり数百バイトだけです。なので **電波の良い場所で先に済ませておく** のが一番効きます。

1. **前日〜開始前に部屋を作る**：主催者は会社や駅など電波の良い場所で「部屋をつくる」
2. **招待URLをLINEグループに送る**（👥 → 「URLをコピー」）
3. **お店に入る前に各自1回開いて参加しておいてもらう**
   - これでページが各スマホに保存され、お店では電波がほぼ無くても一瞬で起動します
   - 参加済みなので、お店では開くだけでそのまま遊べます

遊んでいる途中で電波が途切れても大丈夫です。

- 画面上部に「電波を探しています…」と出ますが、操作はそのまま続けられます
- 回答・公開・「同じ！」は端末に一時保存され、電波が戻った瞬間に自動で送られます（「✓ 電波が戻りました」と表示）
- **ただし、送信待ちのままページを閉じたり再読み込みしたりすると、その操作は消えます**
- 制限時間は端末の時計で進むので、電波が切れてもカウントは止まりません
- 主催者の電波が切れると全体の進行が止まります。**主催者はなるべく電波の入る席・Wi-Fiの近くで**

お店の Wi-Fi がある場合はそれを使うのも手です。キャリアによって地下での入りやすさが違うので、電波が入る人のテザリングに相乗りするのも有効です。

## お題を編集する

お題は番組と同じく **「頭文字」×「テーマ」** の組み合わせです（例：『あ』で始まる、かわいい生き物は？）。
`questions.json` を編集して `index.html` と同じ場所に置き直すだけで反映されます。

```json
{
  "letters": "あいうえおかきくけこ…",
  "themes": [
    {"id": 200, "cat": "社内ネタ", "text": "うちの会社にありがちなものは？"}
  ]
}
```

- `letters`：ランダムで出る頭文字。出しにくい「ぬ・る・を・ん」は初期状態では外してあります（主催者が手動で選ぶことはできます）
- `themes`：頭文字の後ろに続く部分。「〜は？」で終えると自然につながります
- `id` は重複しない数字にしてください（同じ部屋で同じテーマが二度出ないよう管理に使います）
- `index.html` を単体で開いた場合は内蔵のテーマ（97種）×頭文字（42字）が使われます

## 知っておくと良いこと

- **他人に無料枠を使われないための仕組み**
  - ページを開いただけでは Firebase に接続しません（同時接続数を消費しない）。部屋を作る・入るときだけ接続し、部屋を出ると切断します
  - 部屋を作れるのは合言葉を知っている人だけです。合言葉はサーバー側のルールで照合しているので、ページのコードを読まれても分かりません
  - ページは検索エンジンに載らない設定にしてあります
  - 無料プランは上限を超えても課金されません（その時点で新しい接続ができなくなるだけ）

- 無料枠（Spark プラン）は **同時接続100台まで**。忘年会1部屋なら余裕です
- 遊んだ部屋のデータは Realtime Database に残ります。気になったら「データ」タブで `rooms` と `secrets` を削除してください
- 主催者がページを閉じてもゲームは消えません。同じスマホ・同じブラウザで開き直せば主催者に戻れます（別のスマホからは主催者になれません）
- 回答テキストはサーバー上でも本人しか読めない場所に保存され、公開した瞬間に初めて他の人に届きます
